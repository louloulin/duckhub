**需要实现的连接器**:

- [ ] **PostgreSQL连接器**: 使用tokio-postgres库实现连接
- [ ] **文件系统连接器**: 支持CSV、JSON、Parquet格式
- [ ] **REST API连接器**: 支持HTTP数据拉取

**技术要求**:
```rust

csv = "1.3"

reqwest = { version = "0.11", features = ["json"] }
```

**实施步骤**:
1. 更新Cargo.toml依赖

4. 实现文件格式解析器
5. 添加连接池和错误重试机制
6. 编写集成测试
